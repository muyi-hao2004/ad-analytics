# Day18: RAG、Function Calling与Agent实战

---

## 一、RAG 基础

### 1.1 什么是RAG？
RAG = Retrieval-Augmented Generation（检索增强生成）

**核心思想：** 先查资料，再写答案（开卷考试）

### 1.2 完整流程
```
用户提问
    ↓
第1步：把问题转成向量（Embedding）
    ↓
第2步：去向量数据库找最相似的文档
    ↓
第3步：把检索到的文档 + 用户问题 拼成Prompt
    ↓
第4步：发给大模型，生成回答
```

### 1.3 为什么需要RAG？
- 大模型不知道你的私有数据
- 大模型会瞎编
- 知识更新方便（更新知识库就行，不用重新训练模型）
- 成本低（只塞相关的几篇文档）

---

## 二、核心组件

### 2.1 Embedding（向量嵌入）
- 把文字转成一串数字（向量）
- 语义相近的句子，向量也相近
- 常用模型：all-MiniLM-L6-v2（本地）、text-embedding-3-small（OpenAI）

### 2.2 向量数据库
- 专门存向量、快速做相似度搜索的数据库
- 常用：Chroma（轻量本地）、pgvector（PostgreSQL扩展）、Qdrant、Milvus

### 2.3 文档切分（Chunking）
- 把大文档切成500-1000字的小块
- 太大：检索不准；太小：上下文不够

---

## 三、RAG 优化

### 3.1 流式输出（Streaming）
- 大模型一个字一个字蹦出来，不用等全部生成完
- 实现：调用API时加 `stream=True`
- 用户体验：像打字机，不用干等

### 3.2 引用来源（Citation）
- 回答时标注每句话来自哪篇文档
- 提高可信度，可追溯
- 实现：在Prompt里要求大模型标注来源

### 3.3 包装成API
- 用FastAPI把RAG包装成HTTP接口
- 别的程序（比如Agent）可以通过网络调用
- 这样RAG就变成了一个可复用的服务

## 四、Function Calling 原理

### 4.1 什么是Function Calling？
大模型不只输出文字，还能输出"我要调用哪个函数、参数是什么"。

**大模型负责"想"，代码负责"做"。**

### 4.2 工作流程
```
1. 你告诉大模型有哪些工具（工具说明书）
2. 用户提问
3. 大模型判断：我需要调用工具
4. 大模型返回：要调用哪个函数、参数是什么
5. 你的代码真正去执行这个函数
6. 把函数返回的结果再喂给大模型
7. 大模型根据结果生成最终回答
```

### 4.3 工具说明书长什么样？
每个工具要写清楚：
- 函数名（name）
- 功能描述（description）- 最重要！
- 参数列表（parameters）- 参数名、类型、描述
- 哪些参数是必填的（required）

**工具描述写得越清楚，大模型越容易选对。**

## 五、Agent 是什么？

### 5.1 定义
Agent = 大模型 + 一堆工具

大模型自己决定：
- 什么时候该调用工具
- 该调用哪个工具
- 参数怎么填
- 调用完下一步该干嘛

### 5.2 和普通聊天的区别
| | 普通对话 | Agent |
|---|---------|-------|
| 能干什么 | 只能聊天 | 能调用工具干活 |
| 怎么回答 | 靠训练时记住的知识 | 自己查数据、查知识库 |
| 能不能用你的系统 | 不能 | 能，调用你的API |

## 六、项目实战：广告投放智能助手

### 6.1 项目结构
```
ad_agent/
├── tools.py      # 工具层：所有可调用的工具函数
├── agent.py      # Agent核心：大模型决策逻辑
└── README.md     # 项目说明
```

### 6.2 4个工具
| 工具名 | 功能 |
|--------|------|
| `query_ad_data` | 查询广告投放数据 |
| `detect_anomaly` | 检测投放异常 |
| `query_knowledge_base` | 查询知识库 |
| `get_daily_report` | 生成日报 |

### 6.3 效果示例
- 问："今天Facebook的CPA多少？" → 调用query_ad_data
- 问："什么是CPA？" → 调用query_knowledge_base
- 问："Facebook有没有异常？" → 先调用detect_anomaly，再调用query_ad_data查详情
- 问："给我一份日报" → 调用get_daily_report

## 七、关键知识点总结

| 概念 | 一句话解释 |
|------|-----------|
| RAG | 先检索文档，再让大模型基于文档回答 |
| Embedding | 把文字转成向量，语义相近的向量也相近 |
| 向量数据库 | 专门存向量、快速做相似度搜索 |
| Function Calling | 大模型能输出"我要调用哪个函数、参数是什么" |
| Agent | 大模型 + 工具，自己决定用哪个工具干活 |
| 工具说明书 | 告诉大模型有哪些工具、怎么用 |
