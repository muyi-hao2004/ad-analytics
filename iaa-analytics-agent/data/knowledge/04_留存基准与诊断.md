# 留存基准与留存诊断（IAA 视角）

## 为什么留存对 IAA 比 IAP 更关键

IAP 游戏靠少数大额付费用户，可以容忍留存差（付费发生在早期）。
IAA 游戏的收入是「每天看几次广告」的累积，**收入与活跃天数几乎线性相关**：

```
LTV_ad ≈ ARPDAU × 累计活跃天数
```

所以对纯广告变现的产品，**留存不是体验指标，是收入指标**。
D7 留存从 12% 掉到 9%，LTV 大致等比例掉，ROAS 也等比例掉。

**引用时必须带来源，不要说「行业标准是 X%」。**

## 超休闲的留存形态：陡降是正常的

行业报告的共识描述：

- D1 约 40% 以上算「有潜力的产品」；低于 30% 说明吸引力不足（Game Industry Library）
- D7 常掉到个位数；头部能到约 15%
- SolarEngine 数据：超休闲 D1 平均低于 25%，D7 低于 8%

**因此不能用「D7 掉得快」判断产品失败**——这是该品类的常态。
真正的判断标准是：**在用户流失之前，是否已经产生了足够的广告曝光**。
超休闲的商业模式是「海量低价值用户 × 少量曝光」，规模本身就是模型的一部分。

Voodoo 的 Helix Jump 是极端例子：5 亿+ 下载，IAP 只赚约 280 万美元，绝大部分收入来自广告。

## 用留存初步判断渠道质量

留存曲线很难伪装，是最基础的渠道质量信号。**只看形态就能过滤掉大部分问题流量**：

- 真实用户的留存是**平滑的指数衰减**
- 出现陡升、断层 → 数据被人为干预过（机刷、积分墙）
- D1 正常但 D2–D3 断崖归零 → 典型欺诈特征（48 小时内集体消失）
- 「异常平稳」完全不衰减 → 同样可疑

**完整的多维判据不在本篇。** D1 留存与注册转化率的比较、人均启动次数、
CTIT 分布、设备指纹、六个信号的组合判断，全部写在「渠道质量与假量识别」里。

为什么拆开放：同一套判据写在两篇会导致检索时两篇互相抢位（实测确实发生：
问「次留比转化率还高正常吗」，两篇轮流排在前面），而且维护时要改两处、容易改漏。

## 留存与变现的联动判断（实际工作最常用的三条）

1. **留存下滑 + eCPM 正常 → 产品问题**（内容耗尽、广告打扰过度）
2. **留存正常 + eCPM 下滑 → 广告需求问题**（季节性、聚合/竞价配置、地区结构变化）
3. **留存和 eCPM 同时下滑 → 先查是否是自己改了广告频率**
   （这是最常见的人为原因，且改动往往就在几天前，查操作日志能直接定位）

第 3 条为什么重要：**绝大多数「ROAS 突然变差」是自己前几天的操作导致的**，
所以看到下滑的第一动作应该是查操作日志，而不是立刻调预算或删渠道。
