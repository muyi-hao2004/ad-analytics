# IAA 广告变现行业经验

## 变现指标理解

### eCPM（每千次展示收入）
eCPM = 广告收入 / 广告展示次数 × 1000
反映流量变现效率。eCPM 高说明单次展示价值高。

### 留存率
留存率 = 第 N 天活跃用户 / 安装用户
是 IAA 游戏的生命线，留存低意味着用户装完就走，广告收入无法持续。

### 观次（观看次数）
观次 = 激励视频观看次数 / 活跃用户
反映用户看广告的意愿。激励视频是 IAA 主要收入来源。

## 常见问题定位

### ROI 突然下跌怎么办
1. 先看是不是单日异常（可能是节假日、渠道波动）
2. 看操作日志，最近是否有人动过预算或目标
3. 下钻到素材和子渠道，定位是哪个维度拖后腿
4. 排除单日异常后，再决定是否调整

### 留存低怎么办
留存低通常不是投放问题，而是产品问题（游戏质量、新手引导）。
投放侧只能优化素材质量，吸引更匹配的用户。

## 数据分析原则

### 不要只看单点
单日数据波动大，要看趋势（7 天累计）才能下结论。

### 结合操作日志
判断一个渠道/素材好坏，要结合「谁在什么时候改过什么」，
避免重复调整或误判。
