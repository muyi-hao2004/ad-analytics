# Mintegral（MTG）投放机制与运营节奏

## 平台定位

- 汇量科技旗下，主打「开放网络（open internet）」流量，不依赖头部媒体
- 自报规模：日均 4000 亿+ 广告请求、22 亿+ DAU、12 亿+ 日均展示
- 直连 10 万+ 接入 SDK 的应用
- 第三方排名：AppsFlyer 全球游戏 volume Android 第 2 / iOS 第 3；
  Tenjin 广告花费 Top 3；Singular ROI Top 5

**对投放的意义**：Mintegral 的库存来自中小应用，**价格通常低于 Meta/Google，
但流量质量分布更宽**。所以「跑得便宜」和「跑得干净」是两件事，需要分开验证（见渠道质量篇）。

## Target ROAS：三种模式

Mintegral 的智能出价支持三种 ROAS 目标，这是它和纯 CPI 出价的核心区别：

| 模式 | 优化目标 | 适用 |
|---|---|---|
| **IAA ROAS** | 仅应用内广告收入 | 纯广告变现（本项目场景） |
| **IAP ROAS** | 仅应用内购买 | 纯内购 |
| **Hybrid ROAS** | 广告 + 内购合并 | 混合变现 |

**本项目（纯 IAA，无内购）对应 IAA ROAS 模式。**
注意：如果实际有内购但只设 IAA ROAS，会系统性低估用户价值、压低出价、拿不到量。

## 优化窗口与学习期（最重要的落地参数）

| 窗口 | 定义 | 学习期 |
|---|---|---|
| **D0 ROAS** | 安装后 24 小时内的收入 | **5–7 天** |
| **D7 ROAS** | 安装后 7 个自然日内的收入 | **15–20 天** |

**这两条是判断「该不该现在动它」的依据：**

- 刚开启 D7 ROAS 活动 3 天，看到 ROAS 很低 → **不要动**，学习期还没过
- 刚开启 20 天，ROAS 仍不达标 → 可以调整
- 频繁在学习期内调目标 = 反复打断算法学习，效果会更差

## 调整节奏：每周最多 2 次，每次不超过 ±10%

Mintegral 官方明确给出的规则：

> 目标 ROAS 的调整频率**限制在每周 2 次以内，每次调整幅度不超过 ±10%**。
> 过度或频繁的调整会干扰算法、降低整体表现。

这条直接对应一个高频错误：看到 ROAS 低就一次把目标砍 30% 或翻倍。
**正确做法是：小幅（10% 以内）、低频（每周 1–2 次），给算法反应时间。**

与 Unity 的「双周更新一次目标」相比，Mintegral 允许更频繁，但幅度更小。
共同点是：**调整要慢，不要追着日数据调。**

## 目标 ROAS 不是越高越好

官方原话的意思：**目标设太高，算法会只挑高价值用户，导致量级受限。**

这是一个典型的「指标优化陷阱」：

```
目标 ROAS ↑ → 单用户质量 ↑ → 可获取的用户池 ↓ → 总量 ↓ → 总利润可能 ↓
```

所以优化的正确目标是**总利润**，不是单用户 ROAS。
判断方法：把「目标 ROAS × 可获取量」当乘积看，而不是只看 ROAS 那个数。

## 冷启动与数据回传

官方建议的核心一条：**尽早开启全渠道数据回传**。

理由：在 ROAS 优化开启之前，平台就可以开始积累事件样本。
数据越充分，模型起效越快、稳定性越高。

配套的检查项（来自 IAP ROAS 上线文档，机制通用）：

1. 开启对应事件（IAA 场景是广告收入事件 / ILRD）
2. 开启全渠道安装数据回传
3. **与第三方分析（MMP）对比平台数据，差异大要先排查再开 ROAS 优化**
4. 确认产品满足 Target ROAS 的启用条件

**第 3 条容易被跳过但很关键**：如果平台侧和 MMP 侧的收入口径不一致，
算法学到的是错的 LTV，目标 ROAS 就永远调不准。

## CPI + Target ROAS 双线并行

官方建议的组合策略：

- **CPI 出价**关注「量」，适合预算有限时快速起量、冲榜
- **Target ROAS** 关注「质」，追求回本效率
- 两者并行，按需求分配预算，可以突破单一模式的量级天花板

**实践含义**：不要二选一。新品期用 CPI 拿量测素材，成熟期用 ROAS 保效率。

## 品类适配

官方明确说明：在 Mintegral 上，**超休闲、休闲、中度游戏等以 IAA 或 IAA+IAP 混合变现的品类，
Target ROAS 的投放表现最佳**。

这与本项目场景一致（IAA 休闲 / 轻中度）。

## 判断清单

| 情况 | 判断 |
|---|---|
| 活动刚开 3–5 天，D7 ROAS 差 | 学习期未过（需 15–20 天），**不要动** |
| 需要调目标 | 每周 ≤2 次，每次 ≤±10% |
| ROAS 达标但量很小 | 目标可能设太高，考虑下调换规模 |
| 平台 ROAS 与 MMP 差异大 | 先对口径，再开优化 |
| 纯 IAA 无内购 | 用 IAA ROAS 模式，不要用 Hybrid（会高估价值） |
| 想快速起量 | CPI 出价 + ROAS 双线，而不是硬拉高 ROAS 目标 |
