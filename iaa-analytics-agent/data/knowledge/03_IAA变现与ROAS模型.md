# IAA 变现的数学模型：ROAS / ARPDAU / LTV 三者关系

## 核心公式链（所有决策都从这条链推出来）

IAA（纯广告变现）游戏的投放决策，本质是在判断一件事：**一个用户带来的广告收入，是否大于买他的成本**。

```
ROAS   = LTV_ad / CPI
LTV_ad = ARPDAU × 平均活跃天数（留存曲线下面积）
ARPDAU = 人均广告展示次数 × eCPM / 1000
人均展示 = 会话数 × 每会话广告曝光数
```

把三行合并，就得到完整的杠杆清单：

```
ROAS = (会话数 × 每会话曝光 × eCPM / 1000) × 活跃天数 / CPI
       └─ 产品设计 ─┘ └─ 变现设计 ─┘ └ 广告需求 ┘ └─ 留存 ─┘ └ 买量成本 ┘
```

**含义**：ROAS 不达标时，「降 CPI」只是五个杠杆中的一个。而在同一个市场里 CPI 由竞争决定，
投放侧能压的空间很小；真正能改的是**留存天数和 ARPDAU**。这是 IAA 游戏「产品即投放」的原因。

## ARPDAU 的正确拆法

```
Ad ARPDAU = Impressions per DAU × eCPM / 1000
Impressions per DAU = 会话数/人 × 曝光数/会话
```

拆到这一步才能定位问题：

| 现象 | 说明什么 | 改哪里 |
|---|---|---|
| ARPDAU 低，但 eCPM 正常 | 曝光量不够 | 广告位设计 / 会话时长 |
| ARPDAU 低，且 eCPM 低 | 流量卖不出价 | 聚合与竞价、地区结构 |
| ARPDAU 高，但留存掉 | 在拿留存换日收入 | **净损失**，见下 |

**最典型的失败模式**：提高插屏频率让 ARPDAU 涨 10%，同时 D7 留存掉几个点。
因为 ARPDAU 是「每日费率」，LTV 是「费率 × 天数」，用后者换前者几乎总是负收益。
判断方法：任何变现改动都要同时看 ARPDAU 和 D7/D30 留存的 cohort 对比，只看 ARPDAU 一定会做错。

## LTV 的两种算法

**方法一：留存曲线 × ARPDAU（估算用）**

```
LTV = ARPDAU × 累计活跃天数
累计活跃天数 = 1（安装当天）+ D1留存 + D2留存 + … + Dn留存
```

注意是**把整条留存曲线加起来**，不是「D7 留存 × 7」。后者会严重高估。

举例（混合休闲益智，Asomehdi 2026 的算例）：D1 40% / D3 23% / D7 15% / D14 11% / D30 7%，
30 天内累计活跃 4.8 天；ARPDAU $0.12 → D30 LTV = 4.8 × 0.12 ≈ **$0.58**。

**方法二：cohort 累计 ARPU（投放实际用这个）**

```
Dn ARPU = 该 cohort 在 Dn 之前的累计收入 / 该 cohort 安装数
```

优点是可以直接按渠道、国家、平台拆。缺点是要等 cohort 成熟。
实际做法是用「成熟 cohort 的 D90/D7 倍数」外推：`预测 D90 LTV = D7 ARPU × 倍数`。
**倍数必须按平台 × 国家 × 渠道分别算**，iOS Tier1 和 Android Tier3 的衰减速度完全不同。

## CPI 与 LTV 的比例：30%–70%

单看 CPI 没有意义。$3 的 CPI 对一个 LTV $12 的游戏是便宜的，对 LTV $0.40 的游戏是灾难。

实操规则（Game Growth Advisor 2026）：

- **CPI 应落在预期 LTV 的 30%–70%**
- 需要快速回本、或风险承受力低 → 取靠下的 30%
- 有充足现金、愿意换规模 → 取靠上的 70%

这条规则同时解释了一个常见误判：**CPI 低于行业均价 50% 以上，大概率不是捡漏，是流量有问题**（见「渠道质量与假量识别」）。

## 纯 IAA 在 Tier1 买量的结构性困难（关键结论）

一个完整的算术推演（Game Growth Advisor 2026，用 TopOn H1 2025 的 eCPM）：

| 项 | 数值 | 来源 |
|---|---|---|
| 激励视频 eCPM（欧美休闲 Android） | $8.90 | TopOn H1 2025 |
| 人均每日激励观看 | 3–5 次 | 常见设计目标 |
| 推出 Ad ARPDAU | $0.027–0.044 | 计算 |
| 平均活跃天数 | 5–9 天 | 留存曲线积分 |
| **90 天 Ad LTV** | **$0.20–0.45** | 计算 |
| Tier1 Android CPI | $1.20–3.00 | Admiral Media 2026 |

**LTV 比 CPI 低 4–10 倍。** 交叉验证：Liftoff 测到休闲游戏 Android 的 D30 ROAS 仅 **15%**（24 亿安装样本）。
也就是说纯激励变现的休闲游戏，第一个月只能收回约七分之一的买量成本。

**结论：纯 IAA + Tier1 付费买量，在还没做任何定向之前，结构上就很难成立。**
这不是优化技巧问题，是算术问题。

三条出路（原文列了三条，只有一条舒服）：

1. **用 IAP 承担经济系统**（混合变现里 IAP 通常占收入 40%–60%）——最高杠杆，且不需要加预算就能验证
2. **去便宜市场**（LATAM / 东南亚 CPI 降到 $0.15–0.60，但激励 eCPM 同时降到 $1.60–2.20，
   比例改善没有直觉上那么大，某些市场广告格式的优先级甚至反转）
3. **不做付费买量**：商店优化、自然量、交叉推广

**对纯 IAA 项目的判断标准**：如果只有广告收入且主投 Tier1，先确认 ARPDAU 是否显著高于品类均值
（例如靠高频激励把 ARPDAU 做到 $0.10+），否则算不过账。

## 地区结构会改变结论

同样的游戏，换个市场结论可能反转：

- 美国 eCPM 高（CPM 约 $16.5，Adjust 2026）但 CPI 也高（休闲 Android $1.50–3.50）
- 印度 CPI 低（$0.08–0.30）但 CPM 只有约 $0.6
- 结果是：**低 CPI 市场不等于高 ROAS 市场**，要看两边比值

实操判断：`eCPM / CPI` 的比值比任何一个绝对值都更能说明该市场适不适合纯 IAA。
