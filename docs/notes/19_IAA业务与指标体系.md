# IAA 业务与指标体系

> **本篇覆盖**：IAA 商业模式、投放层级、买量侧 vs 变现侧的指标分野、核心指标全表、双轴视角（日历 vs cohort）、归因规则、优化师的日常决策逻辑、口径陷阱。
>
> 数据岗面试里，「你懂业务吗」这一票，几乎全靠这一篇。指标公式谁都会背，能说清「口径怎么定义、为什么这么定义」的人很少。

---

## 一、IAA 是什么，和 IAP 差在哪

| | IAA（In-App Advertising） | IAP（In-App Purchase） |
|---|---|---|
| 收入来源 | 展示广告（激励视频 / 插屏 / Banner） | 用户内购、订阅 |
| 关键指标 | eCPM、展示次数、观次 | ARPU、ARPPU、付费率、订阅留存 |
| 增长逻辑 | 把量买进来 → 用户看广告 → 变现 | 把量买进来 → 用户付费 |
| 回本模型 | 靠广告累计收入追平买量成本 | 靠付费累计收入追平买量成本 |

用户经历过的业务是 **海外休闲游戏 + 纯 IAA**（美国 T0 市场，网赚类），**无内购、无订阅**。这个前提很重要——它决定了所有指标都围绕「广告展示」展开，而不是围绕「付费转化」。

> 面试时如果被问「你做的是 IAA 还是 IAP」，答：纯 IAA，收入全部来自广告变现，所以核心指标是 eCPM × 展示次数，而不是 ARPU。

## 二、投放层级：三层结构

```
广告系列 campaign（最大，绑定投放人 / 优化师）
   └── 广告组 ad_group（定向：国家、渠道、出价策略）
          └── 素材 creative（用户真正看到的视频/图片）
```

几点必须清楚：

- **campaign 是决策单元**。优化师说「这个系列跑不动，删掉」，删的是 campaign 层。
- **出价策略挂在 campaign 上**。建系列时选固定策略之一：`D7_ROAS` / `D0_ROAS` / `CPI`（ROAS 填百分比，CPI 填美元）。
- **素材归因用 last-click**：一个安装算给「最后一次点击的那个素材」。这意味着素材之间会互相抢功，跨素材比较要谨慎。
- **看数的维度更多**：国家（T0/T1 分层）、子渠道（Unity / Kwai / NewsBreak / AppLovin 等）、投放人。

## 三、买量侧 vs 变现侧：最容易混的两个 eCPM

这是这个行业最容易被问倒、也最能体现「真做过」的地方。

| | 买量侧（Acquisition） | 变现侧（Monetization） |
|---|---|---|
| 谁付钱 | **你付给**媒体渠道 | **广告主付给**你 |
| eCPM 含义 | 你买 1000 次曝光的成本 | 你卖 1000 次曝光拿到的收入 |
| 高好还是低好 | **越低越好** | **越高越好** |
| 关键指标 | CPI、CTR、CVR、CPA | eCPM、观次、展示数、收入 |
| 时间轴 | 单轴（投放当天 report_date） | 双轴（安装日 × 回传日） |

**两个 eCPM 完全不是一回事，但经常在同一个看板上出现，一定要标清楚是哪一个。**

同理，买量侧的 CTR / CVR 和变现侧的 CTR / CVR 也不同口径：
- 买量侧 CTR = 广告被点击 / 广告被曝光（素材好不好）
- 变现侧（激励视频）看的是**观次**，不是点击率

## 四、核心指标全表

### 4.1 成本类（买量侧）

| 指标 | 公式 | 含义 | 异常意味着 |
|---|---|---|---|
| CTR | 点击 / 曝光 | 素材吸引力 | 低 → 素材不行，换素材 |
| CVR | 安装 / 点击 | 落地页 / 商店页转化能力 | 低 → 商店页或包体有问题 |
| CPC | 花费 / 点击 | 买一次点击多少钱 | 高 → 出价过高或竞争激烈 |
| CPI | 花费 / 安装 | **买一个安装多少钱**（IAA 核心成本指标） | 高 → 量贵，要么降价要么停 |
| CPA | 花费 / 转化 | 买一个转化多少钱（转化定义随业务变） | 高 → 亏钱 |

### 4.2 收入类（变现侧）

| 指标 | 公式 | 含义 |
|---|---|---|
| eCPM | 广告收入 / 展示次数 × 1000 | 每千次展示能赚多少 |
| 观次 | rewarded_views / active_users | 用户平均主动看几次激励视频（**用户主动行为，不是被动曝光**） |
| ARPU | 总收入 / 活跃用户数 | 单用户平均贡献收入 |
| ARPPU | 总收入 / 付费用户数 | 单付费用户平均贡献（IAP 场景更常用） |
| LTV | 单用户生命周期累计收入 | 决定「出多少钱买一个用户还划算」 |

### 4.3 回报类（决策核心）

| 指标 | 公式 | 说明 |
|---|---|---|
| ROAS | 收入 / 花费 | 广告支出回报率，>1 才回本 |
| **D0 ROAS** | 第 0 天收入 / 花费 | 当天回本能力，快速判断 |
| **D7 ROAS** | 累计到第 7 天收入 / 花费 | **业务核心目标：70%** |
| ROI | (收入 − 花费) / 花费 | 净回报率，和 ROAS 差一个 1 |
| 留存率 ret_n | 第 n 天仍活跃 / 安装数 | 决定长线 LTV |

> **D7 ROAS 70% 是这条业务线的目标值**。它的含义是：买量花 100 块，7 天内能收回 70 块，剩下 30 块靠 7 天以后的长期收入补齐。所以「D7 ROAS 不达标」不等于「立刻亏」，但意味着回本周期被拉长，需要看留存能不能撑住。

### 4.4 ROAS 和 ROI 别混

```
ROAS = 收入 / 花费        → 1.0 是盈亏平衡点
ROI  = (收入 − 花费) / 花费 → 0 是盈亏平衡点
ROI  = ROAS − 1
```

面试时说错这两个的换算关系，会被直接判定「没真算过账」。

## 五、双轴视角：同一批数据的两种读法

这是用户项目里最有技术含量的业务设计，值得单独讲。

### 5.1 两个日期轴

| 轴 | 含义 | 用来回答 |
|---|---|---|
| **install_date**（安装日） | 用户是哪天装的 | cohort 视角：这批用户后续表现如何 |
| **report_date**（回传日） | 平台哪天把数据推回来的 | 日历视角：今天账上有多少钱 |

### 5.2 两种口径的差别（举例）

假设 10-01 安装了 1000 个用户：

- **按 install_date 切 10-01** → 这 1000 人从 D0 到 D7 的完整表现曲线（cohort 分析）
- **按 report_date 切 10-01** → 10-01 这天收到了多少钱，其中包含 09-24 安装的人今天产生的收入（日历收入）

**同一个「10-01 的收入」在两个口径下数字完全不同。** 这就是为什么必须建双轴事实表——一张表同时保留两个维度，才能既看日报又看 cohort。

### 5.3 DWS 层的 day_offset 陷阱

宽表列名 `dact1 / drev2 / dimp3` 里的数字，是「**安装后第 N 天**」，不是日历日期。

```
10-01 的 drev2 = 10-03 那天，10-01 这批用户产生的收入
10-02 的 drev1 = 10-03 那天，10-02 这批用户产生的收入
```

两个值都是 10-03 发生的事，但属于不同 cohort。**如果按列名直接横向求和，会把不同批次混在一起。** 这是数仓 pivot 之后最常见的口径错误。

## 六、归因规则

| 场景 | 规则 | 影响 |
|---|---|---|
| 素材归因 | **last-click** | 最后一次点击的素材拿全部功劳；多素材协同的效果被低估 |
| 渠道归因 | 按平台回传的 channel | 平台自归因，存在各平台互相抢量的可能 |
| 国家归因 | 按安装时的 IP / 商店地区 | 跨区用户会算错 |

**归因窗口**（click 到 install 之间允许多久）会直接影响 CVR 和 CPI。不同平台窗口不同（常见 1 天 / 7 天），跨平台对比时必须先对齐窗口。

## 七、优化师的日常决策逻辑

用户实习时做的就是这件事，面试可以直接讲。

### 7.1 每天看什么

1. 昨天各 campaign 的花费、CPI、D7 ROAS（或预估）
2. 新上的素材 CTR / CVR 有没有跑出来
3. 有没有花费异常（暴涨 / 不动）
4. 子渠道质量（哪个渠道 CPI 低但留存差）

### 7.2 三种动作

| 动作 | 触发条件（经验值） | 风险 |
|---|---|---|
| **加预算** | ROAS 达标且稳定、CPI 低于目标 | 加太猛会导致成本上升、量级质量下降 |
| **保持** | 数据在目标区间内波动 | 样本量太小就下结论 |
| **暂停 / 删** | 花费超阈值但 ROAS 持续不达标、CPI 严重超标 | 删太早会错过起量期（新素材有学习期） |

### 7.3 「学习期」这个概念

平台算法需要一定转化量才能完成模型学习（通常 20-50 个转化）。**在学习期内数据差不代表素材差**，过早关掉是新手最常见的错误。

> 这一条能直接解释「为什么不能纯靠规则自动化」——需要判断「数据差是因为素材差，还是因为在学习期」。这也是 Agent 决策必须带理由、必须留人工确认的业务原因。

### 7.4 判断的难点

- 样本量：一天 3 个安装的 campaign，转化率波动毫无统计意义
- 滞后性：D7 ROAS 要等 7 天，等不起；所以要用 D0/D1 预估
- 混杂因素：CPI 涨了，可能是素材问题，也可能是大盘竞价环境变了
- 多目标冲突：加预算能拿更多量，但会推高 CPI

## 八、口径陷阱清单（面试高频）

| 陷阱 | 正确做法 |
|---|---|
| 平均值的平均 | 先加总分子分母再相除，不能对每行比率取平均 |
| 分母为 0 | 零曝光记录必须先过滤或做除零保护，否则 CTR 无意义 |
| 留存率分母 | 用安装数，不是当日活跃数 |
| 观次 ≠ 展示数 | 观次是用户主动触发的激励视频，展示包含被动曝光 |
| 跨 cohort 求和 | drevN 列不能直接横向加总 |
| 时区 | 平台回传可能带时区后缀（如 `+08:00`），跨时区对齐到同一基准日 |
| 归因窗口不一致 | 跨平台比较前先统一 |
| ROAS 与 ROI 混用 | ROI = ROAS − 1 |
| 买量/变现 eCPM 混用 | 必须标注是哪一侧 |
| 小样本结论 | 转化数 < 20~30 时不要下「素材不行」的结论 |

## 九、异常检测的五个业务信号

用户项目里实现的 5 种异常，本质就是优化师每天在找的东西：

| 异常 | 判断依据 | 业务动作 |
|---|---|---|
| 花费暴涨 | 环比超过阈值 | 查是不是出价或预算配错 |
| CTR 过低 | 低于历史分位 | 换素材 |
| CVR 过低 | 低于历史分位 | 查商店页 / 包体 / 版本 |
| CPI 过高 | 超过目标值 | 降价 / 停投 |
| 零曝光 | 展示 = 0 | 查审核状态、预算、定向过窄 |

阈值怎么定：初期用业务经验值，成熟后改用统计方法——**3-sigma（均值 ± 3 倍标准差）** 或 **IQR（四分位距）**。数学背景在这里是加分项，可以主动提。

## 十、面试速查

- **IAA 和 IAP 区别？** → IAA 靠广告变现，核心是 eCPM × 展示；IAP 靠内购，核心是 ARPU / 付费率。
- **两个 eCPM 有什么区别？** → 买量侧是「你买曝光的成本」，越低越好；变现侧是「你卖曝光的收入」，越高越好。
- **D7 ROAS 70% 是什么意思？** → 买量花 100 块，7 天内收回 70 块，剩余靠长期收入补齐；不达标意味着回本周期拉长。
- **ROAS 和 ROI 关系？** → ROI = ROAS − 1。
- **为什么要双轴事实表？** → install_date 看 cohort 表现，report_date 看日历收入，同一份数据两种读法。
- **drev2 是日历日期吗？** → 不是，是安装后第 2 天，不同 cohort 的 drevN 会落在同一日历日。
- **为什么不直接对每行指标取平均？** → 比率的平均不等于整体的比率，必须先加总分子分母再相除。
- **为什么不能纯规则自动化投放决策？** → 学习期、小样本、滞后性、多重混杂因素，需要判断而非阈值。
- **归因用什么规则？** → last-click，install 归给最后一次点击的素材。
- **异常阈值怎么定？** → 经验值起步，成熟后用 3-sigma 或 IQR。
- **零曝光为什么要删？** → 分母为 0，CTR 无意义，且说明广告根本没投出去。
- **观次是什么？** → 用户主动看激励视频的平均次数，rewarded_views / active_users。
