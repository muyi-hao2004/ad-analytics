## 一、函数的基本格式

```python
def 函数名(参数1, 参数2, ...):
    """函数说明（可选）"""
    函数体（缩进4个空格）
    return 返回值（可选）
```

| 部分 | 说明 |
|---|---|
| `def` | 定义函数的关键字，固定小写 |
| 函数名 | 用小写字母+下划线，如 `load_data` |
| `(参数)` | 输入，可以没有，多个用逗号隔开 |
| `:` | 必须有，表示下面是函数体 |
| 缩进 | 函数体必须缩进4个空格 |
| `return` | 输出结果，可选 |

## 二、return 用法（核心）

### return 是什么？
函数的**输出**，把结果从函数里递出来，你可以用变量接住继续用。

### return vs print（最容易搞混）

| | print | return |
|---|---|---|
| 作用 | 在屏幕上显示给人看 | 把结果递出来给程序用 |
| 能存变量吗 | 不能 | 能 |
| 能继续计算吗 | 不能 | 能 |

> **记住：print是给人看的，return是给程序用的。**

### return 的5种用法

1. **返回一个值**（最常用）：`return result`
2. **返回多个值**：`return ctr, cvr, cpc`（用逗号隔开）
3. **没有return**：函数默认返回 `None`
4. **return后面的代码不执行**：函数遇到return就结束
5. **提前return**：先处理异常情况提前返回，正常代码放后面（early return）

## 三、大括号 `{}` 的4种用法

> 普通函数传参**永远不用大括号**！大括号是下面这4种用途。

| 用法 | 在哪用 | 例子 |
|---|---|---|
| **f-string占位符** | 字符串前有f，填变量值 | `print(f"你好{name}")` |
| **字典定义** | 定义键值对集合 | `{"name": "小明", "age": 20}` |
| **集合定义** | 定义无序不重复元素 | `{1, 2, 3}` |
| **format占位符** | 老写法，后面有.format() | `"你好{}".format(name)` |

### 传参的正确写法

```python
multiply(3, 4)           # 位置参数（直接写值）
multiply(a=3, b=4)       # 关键字参数（用等号，不是冒号！）
multiply(**params)        # 字典解包（params是字典，用**）
```

> **常见错误**：`multiply(a: 3, b: 4)` —— 传参不能用冒号，冒号是类型注解的语法，传参用等号或直接写值。

## 四、常见错误清单

| 错误 | 正确写法 | 原因 |
|---|---|---|
| 函数后面没加冒号 | `def func():` | 必须有冒号 |
| 函数体没缩进 | 缩进4个空格 | Python靠缩进区分函数体 |
| `result = {a} * {b}` | `result = a * b` | 大括号是集合/字典，变量直接写 |
| `func(a: 1, b: 2)` | `func(1, 2)` 或 `func(a=1, b=2)` | 传参用等号或直接写值，不用冒号 |
| 用print当返回值 | 用return返回结果 | print只显示不返回 |
